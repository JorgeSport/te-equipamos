# Newsletter Landing Base · Te Equipamos

Base reutilizable para captar suscriptores de Te Equipamos con Klaviyo.

## Estado

- Guardada solo como base dentro del repositorio.
- No está integrada en `gh-pages/` ni en el Hub público.
- No debe publicarse automáticamente como una landing comercial de producto.
- Está marcada con `noindex,nofollow` mientras se use como plantilla.

## Integración Klaviyo

La base ya usa:

- Public Key: `XpumF8`
- Form ID: `TDtyXY`
- Botones que abren el formulario oficial mediante `openForm`.

## Estructura

1. Hero de captación.
2. CTA principal de suscripción.
3. Beneficios / categorías.
4. Referencias de productos reales.
5. CTA final de suscripción.
6. Diseño responsive para móvil y escritorio.

## Uso recomendado

Cuando se quiera usar en una campaña de Facebook u otro canal:

1. Duplicar esta carpeta o copiar `index.html` a una landing nueva.
2. Cambiar título, textos, imágenes y referencias de productos si hace falta.
3. Mantener Klaviyo como objetivo principal.
4. Revisar móvil y escritorio.
5. Solo después de aprobarla, publicarla en el repositorio/URL que se decida.

## Regla

Esta carpeta es una **base**, no una landing de producto del sistema `1 producto = 1 repo = 1 landing`.
